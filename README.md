# Президентски избори 2026

Интерактивни графики за президентските избори в България (25.10.2026):

- Гюров срещу Йотова по области (МИР), градове и общини, с карта на България.
- Стара Загора по секции.
- Резултати и активност в страната.

**Сайт:** https://nkoichev.github.io/izbori2026/

Сайтът е статичен: една HTML страница с Plotly.js и JSON данни. Данните са от протоколите на СИК (results.cik.bg). Процентите са от действителните гласове, включително „Не подкрепям никого“, както ги смята ЦИК. Границите на областите са от [geoBoundaries](https://www.geoboundaries.org/) (public domain).

## Обновяване на данните

```
python tools/build_data.py <папка с CSV> --round 1
```

Скриптът записва `data/round<N>.json`. За втори тур пусни го с `--round 2`.
